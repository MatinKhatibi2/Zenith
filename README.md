# 🌱 Zenith — دفترچه‌ی رشد شخصی

اپلیکیشن شخصی مدیریت **وظایف**، **عادت‌ها + پومودورو + یادآور**، **یادداشت‌ها** و **مالی**،
همراه با دستیار هوشمند («جوانه») که بر اساس روند واقعی داده‌های خودت کمکت می‌کنه.

همه‌چیز **آفلاین و روی خود دستگاهته** — هیچ سروری در کار نیست. یک کدبیس، چهار خروجی:
وب (PWA، قابل نصب روی گوشی و دسکتاپ)، ویندوز (exe)، مک (dmg)، اندروید (apk).

---

## 📁 ساختار پوشه‌ها

```
zenith/
├─ web/                   ← خود اپ (HTML/CSS/JS خالص، بدون نیاز به build)
├─ electron/              ← پوسته‌ی دسکتاپ (ویندوز/مک/لینوکس)
├─ android-capacitor/      ← پوسته‌ی اندروید
├─ .github/workflows/      ← ساخت خودکار و رایگان exe/dmg/apk با GitHub Actions
└─ README.md               ← همین فایل
```

## 🚀 سریع‌ترین راه برای امتحان کردن (همین الان، بدون نصب هیچی)

پوشه‌ی `web` خودش یک اپ کامل و کاربردیه. کافیه فایل `web/index.html` رو در مرورگر (Chrome/Edge/Safari) باز کنی.

⚠️ نکته‌ی مهم: وقتی فایل رو مستقیم دو-بار-کلیک می‌کنی، همه‌چیز کار می‌کنه (وظایف، عادت‌ها، مالی، پومودورو) **به‌جز** نصب PWA
روی صفحه‌ی اصلی گوشی و کار کردن کامل سرویس‌ورکر (که مرورگرها فقط روی آدرس‌های واقعی http/https فعالش می‌کنن، نه فایل محلی).

### برای تجربه‌ی کامل (نصب روی گوشی، آدرس اینترنتی واقعی) — رایگان و بدون کدنویسی:

1. برو به **netlify.com** → بساز یک حساب رایگان.
2. توی داشبورد Netlify، پوشه‌ی `web` رو با موس بکش و روی صفحه رها کن (drag & drop).
3. Netlify ظرف چند ثانیه یک آدرس مثل `https://zenith-xxxx.netlify.app` بهت میده.
4. این آدرس رو روی گوشی باز کن:
   - **iOS (سافاری):** دکمه‌ی Share → «Add to Home Screen»
   - **اندروید (کروم):** منوی سه‌نقطه → «Add to Home screen» / «Install app»

از این لحظه، Zenith دقیقاً مثل یک اپ نصب‌شده روی صفحه‌ی اصلی گوشیته، کاملاً آفلاین کار می‌کنه، و هر آپدیتی که بعداً به فایل‌های `web` بدی رو خودکار می‌گیره.

> جایگزین‌های دیگه‌ی Netlify: Vercel، Cloudflare Pages، GitHub Pages — همه رایگان و مشابه.

## 🖥️📱 گرفتن فایل exe / dmg / apk واقعی (خودکار و رایگان با GitHub Actions)

من نمی‌تونم این فایل‌ها رو خودم کامپایل کنم (نیاز به ابزارهای مخصوص ویندوز/مک/اندروید دارن)، ولی یک فایل
آماده گذاشتم (`.github/workflows/build.yml`) که این کار رو **به‌صورت خودکار و رایگان** روی سرورهای گیت‌هاب انجام میده:

### مراحل:

1. یک حساب رایگان توی **github.com** بساز (اگه نداری).
2. یک ریپازیتوری جدید (Repository) بساز — می‌تونه Private هم باشه.
3. کل پوشه‌ی `zenith` (همینی که الان داری) رو توش آپلود کن:
   - ساده‌ترین راه: توی صفحه‌ی ریپازیتوری، دکمه‌ی «Add file → Upload files» رو بزن و همه‌چیز رو بکش و رها کن.
4. برو به تب **Actions** بالای صفحه‌ی ریپازیتوری. اگه پیشنهاد enable workflow داد، قبول کن.
5. ورک‌فلوی «Build Zenith» رو می‌بینی. اگه خودکار اجرا نشد، دکمه‌ی **Run workflow** رو بزن.
6. حدود ۵ تا ۱۵ دقیقه صبر کن (۴ نسخه همزمان ساخته می‌شن: ویندوز، مک، لینوکس، اندروید).
7. وقتی سبز شد ✅، روی اجرا (run) کلیک کن، پایین صفحه بخش **Artifacts** رو ببین:
   - `zenith-desktop-windows-latest` → فایل نصب ویندوز (.exe)
   - `zenith-desktop-macos-latest` → فایل مک (.dmg)
   - `zenith-desktop-ubuntu-latest` → فایل لینوکس (.AppImage)
   - `zenith-android-apk` → فایل نصب اندروید (.apk)
8. هرکدوم رو دانلود کن (به‌صورت zip میاد، فایل اصلی داخلشه).

### نکات مهم درباره‌ی این فایل‌ها:

- **ویندوز:** چون فایل امضای دیجیتال رسمی (که هزینه داره) نداره، ویندوز Defender SmartScreen ممکنه اول بگه
  «Windows protected your PC». روی **More info → Run anyway** بزن. این طبیعیه و برای هر برنامه‌ی امضانشده‌ای پیش میاد.
- **مک:** چون امضا/notarize نشده (که نیاز به حساب Apple Developer با هزینه‌ی سالانه داره)، macOS اول اجازه‌ی
  اجرا نمیده. راست‌کلیک روی برنامه → **Open** → دوباره **Open** رو تأیید کن. این کار فقط بار اول لازمه.
- **اندروید (apk):** این یک نسخه‌ی «debug» است (برای استفاده‌ی شخصی کاملاً کافیه). موقع نصب باید تیک
  «نصب از منابع ناشناس» رو در تنظیمات گوشی فعال کنی.

اگه بعداً خواستی این هشدارها رو کامل حذف کنی (مثلاً برای انتشار عمومی)، نیاز به حساب توسعه‌دهنده در
Apple ($99/سال) و/یا گواهی امضای کد ویندوز داری — برای استفاده‌ی شخصی/خانوادگی لازم نیست.

## 🛠 روش جایگزین: ساخت روی سیستم خودت (برای کاربران حرفه‌ای‌تر)

اگه Node.js (نسخه ۱۸ به بالا) نصب داری:

```bash
# نسخه‌ی دسکتاپ
cd electron
npm install
npm run build:win     # فقط روی ویندوز
npm run build:mac     # فقط روی مک
npm run build:linux   # روی لینوکس

# نسخه‌ی اندروید (نیاز به Android Studio / Android SDK نصب‌شده داره)
cd android-capacitor
npm install
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

خروجی‌ها در `electron/dist/` و `android-capacitor/android/app/build/outputs/apk/debug/` قرار می‌گیرن.

## 🤖 فعال‌سازی دستیار هوشمند («جوانه»)

این اپ سرور نداره، پس دستیار هوشمندش با **کلید API خودت** کار می‌کنه:

1. برو به **console.anthropic.com** و یک کلید API بساز (پرداخت به‌ازای مصرف؛ با مدل پیش‌فرض Haiku هزینه‌ی
   هر پیام معمولاً کسری از سنت است).
2. داخل اپ برو به **تنظیمات → دستیار هوشمند**، کلید رو وارد کن.
3. کلید فقط روی همون دستگاه ذخیره میشه و مستقیماً (بدون واسطه) به Anthropic ارسال میشه.

## 🔒 داده‌ها و حریم خصوصی

- همه‌ی اطلاعات (وظایف، عادت‌ها، یادداشت‌ها، مالی) **فقط روی همون دستگاه** ذخیره میشه؛ هیچ سروری در کار نیست.
- برای انتقال بین دستگاه‌ها یا داشتن نسخه‌ی پشتیبان: **تنظیمات → پشتیبان‌گیری → دریافت فایل JSON**، و در دستگاه
  جدید همون فایل رو از **بازیابی از فایل پشتیبان** وارد کن.
- چون وب، دسکتاپ و اندروید هرکدوم مرورگر/حافظه‌ی جدا دارن، اطلاعات بین‌شون خودکار همگام نمیشه — پشتیبان‌گیری
  دستی همین الان راه‌حلشه. اگه بعداً خواستی، می‌شه یک همگام‌سازی ابری اختیاری (مثلاً با یک دیتابیس ساده) اضافه کرد.

## ⚠️ محدودیت‌های شناخته‌شده

- **یادآورها (Alarms):** فقط تا وقتی برنامه باز/در حال اجراست کار می‌کنن (چه تب مرورگر، چه اپ دسکتاپ/موبایل).
  برای زنگ هشدار واقعی حتی وقتی اپ کاملاً بسته‌ست، باید بعداً یک پلاگین نوتیفیکیشن بومی (مثل
  `@capacitor/local-notifications`) اضافه بشه — زیرساخت فعلی برای این ارتقا آماده‌ست.
- **نمودارها و فونت فارسی** از اینترنت (CDN رایگان) بارگذاری می‌شن؛ بار اول به اتصال اینترنت نیاز دارن، بعدش
  توسط سرویس‌ورکر کش میشن. اگه کاملاً آفلاین باز بشه و قبلاً هم آنلاین نبوده، نمودارها یک پیام جایگزین ساده نشون میدن.
- فایل‌های exe/dmg/apk تولیدشده امضای رسمی ندارن (توضیح در بخش بالا).
